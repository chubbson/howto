## Disk Layout

```
nvme0n1p1  512MB   EFI (unencrypted)
                   └── GRUB + kernel + initramfs
nvme0n1p2  100GB   Free (future dual boot)
nvme0n1p3  ~3.3TB  LUKS encrypted (Argon2id)
                   └── LVM vg0
                       ├── swap    100GB
                       ├── root    400GB  btrfs
                       ├── home    2TB    btrfs
                       └── vm      923GB  xfs
nvme0n1p4  2GB     winRE (untouched)
```

See [[luks]] for encryption details.

## Boot Flow

```
UEFI → GRUB (silent)
→ kernel starts
→ PIN prompt → SoloKey touch OR Enter → passphrase
→ LUKS unlocks → Arch boots
```

See [[solo2]] for SoloKey setup.

## Screenshots

### Tools

```bash
sudo pacman -S flameshot pinta
```

- **flameshot** — region/fullscreen capture with pointer visible and live annotation during capture
- **pinta** — Paint.NET-style image editor for post-capture annotation, cropping, drawing

### Usage

```bash
flameshot gui          # interactive: select region, annotate, save/copy
flameshot screen       # full screen to clipboard
flameshot full -p ~/   # full screen saved to home
```

In the flameshot GUI toolbar: arrows, rectangles, text, blur, and a pointer tool are available before saving.

### GNOME integration

Bind `flameshot gui` to `Print` key:

**Settings → Keyboard → View and Customize Shortcuts → Custom Shortcuts → +**

| Name | Command | Shortcut |
|------|---------|----------|
| Screenshot | `QT_QPA_PLATFORM=xcb flameshot gui` | `Print` |

> Wayland requires `QT_QPA_PLATFORM=xcb` — portal method does not work on this setup.
